## 零基础精讲：把这一节慢下来

### 先看一个具体场景

zip 像拉拉链：words 的第一个元素和 labels 的第一个元素扣在一起。若一边更短，普通 zip 会在短边结束时悄悄停下。

### 数据究竟怎样一步步变化

1. 准备两个或多个序列
2. 取各序列同一位置的元素
3. 组成一个元组
4. 任一输入耗尽时默认停止

把上面四步和流程图对照起来：

> 序列 A → 序列 B → 同位置拉链 → 元组流/最短截止

这里的箭头表示“左边的数据经过一次处理，变成右边的数据”，不是四个需要孤立背诵的名词。

### 第一次读代码，只盯住这一件事

示例有 3 个词却只有 2 个标签，所以只会输出 2 对。用 strict=True 可以让这种错误直接报出来。

运行前先在纸上写出你预计的结果；即使猜错，也要指出自己是在哪个箭头上理解错了。这样比复制代码后看到“能运行”更接近真正学会。

### 本节暂时不要误会

zip 不会自动补空值，默认静默截短可能让训练数据错位。

用一句话过关：**zip 像拉拉链：第一个序列的第 1 项和第二个序列的第 1 项合在一起，然后继续下一位置。n-gram 的简洁写法正利用了这种对齐。**

## 真正看懂这节：`zip` 只做“同位置配对”

先看两个列表：

```python
words = ["包装", "物流", "客服"]
labels = [0, 1, 0]
```

`zip(words, labels)` 得到：

```text
("包装", 0)
("物流", 1)
("客服", 0)
```

```mermaid
flowchart LR
    A1["包装"] --> Z1["(包装, 0)"]
    B1["0"] --> Z1
    A2["物流"] --> Z2["(物流, 1)"]
    B2["1"] --> Z2
    A3["客服"] --> Z3["(客服, 0)"]
    B3["0"] --> Z3
```

它不会根据词义找配对，也不会排序；只把各序列索引相同的元素合成元组。

### 为什么叫“拉拉链”

```text
序列 A：a0  a1  a2
序列 B：b0  b1  b2
结果： (a0,b0) (a1,b1) (a2,b2)
```

有三个输入序列时，每个元组就有三项。`zip` 的结果也是惰性迭代器，通常用 `list(...)` 查看。

### 长度不同时会发生什么

```python
list(zip(["包装", "物流", "客服"], [0, 1]))
# [("包装", 0), ("物流", 1)]
```

默认在最短序列结束时停止，“客服”会静默丢失。这对训练数据非常危险：文本和标签错位或缺失时，程序可能不报错。

在支持的现代 Python 中，可以用：

```python
list(zip(words, labels, strict=True))
```

长度不一致时直接报错。若项目环境不支持 `strict=True`，就先显式断言 `len(words) == len(labels)`。

### `zip(*nested)` 中的星号做了什么

```python
nested = [
    ["我", "爱", "NLP"],
    ["你", "学", "Python"],
]
```

`*nested` 先把两个内层列表作为两个独立参数交给 `zip`：

```python
zip(
    ["我", "爱", "NLP"],
    ["你", "学", "Python"],
)
```

结果像矩阵转置：

```text
("我", "你")
("爱", "学")
("NLP", "Python")
```

```mermaid
flowchart TB
    A["两行 × 三列"] --> B["zip(*rows)"]
    B --> C["三组 × 每组两项"]
    C --> D["按列对齐"]
```

下一节构造 n-gram 时，会先制造多个错位切片，再用 `zip(*slices)` 把同一窗口位置的词对齐。现在只要先掌握“星号解包，zip 按位置合并”。

## 老师原声整理稿（按讲解顺序）

### 0:00–2:54　文本特征处理包含两件事

老师进入文本特征处理：一是加入 n-gram，让模型看到相邻词组；二是把序列截断或补齐到统一长度。

n-gram 是连续 n 个词或字组成的特征。unigram 保留单词，bigram 再加入相邻两词，trigram 再加入相邻三词。n 越大并不必然越好：组合空间迅速膨胀，短句甚至没有足够长度，因此实践中常用 1–3，课程重点掌握 bigram。

### 2:54–6:49　给组合分配独立特征

老师用“水 / 敲动 / 我心”等词和整数 ID 说明：相邻两词组合后应当被视为新的特征，也需要自己的唯一编号，不能把两个 ID 直接写在一起当十进制数。

加入 bigram 后，原 unigram 通常仍保留：

```text = [w1, w2, w3, w4, w5]
bigram = [(w1,w2), (w2,w3), (w3,w4), (w4,w5)]
features = text + bigram
```

这样既保留单词身份，又增加局部语序。代价是特征数更多、低频组合更稀疏。

### 6:49–9:46　先补 zip：按位置组合多个迭代对象

老师先用两个不等长列表演示 zip。它返回惰性 zip 对象，转成 list 后得到元组；输出长度等于最短输入，较长列表尾部会被丢弃。

```python
list(zip([1,2,3,4,5,6], [2,3,4]))
# [(1,2), (2,3), (3,4)]
```

### 9:46–14:13　zip(*nested) 的星号是解包

若直接 `zip(nested)`，zip 只收到一个参数，于是每行会成为单元素元组；`zip(*nested)` 会把内层列表拆成多个位置参数，再按列组合。

```python
rows = [[1,2,3], [3,4,5]]
list(zip(rows))   # [([1,2,3],), ([3,4,5],)]
list(zip(*rows))  # [(1,3), (2,4), (3,5)]
```

老师反复用“整体”和“拆出里面每个元素”解释星号。这个概念将在下一节用滑动切片生成 n-gram。

## 零基础先记住

- zip(a, b) 返回惰性迭代器
- 默认在最短输入结束处停止
- 解包 zip(*pairs) 可把成对数据重新拆列

## 最小可运行代码

在项目根目录运行下面代码。课程原理的标准库版本集中在 [text_preprocessing_from_scratch](../../text_preprocessing_from_scratch/README.md)；需要 jieba、PyTorch、FastText 等的示例，请先按代码注释安装依赖。

```python
words = ["我", "爱", "NLP"]
labels = ["代词", "动词"]
pairs = zip(words, labels)
print(list(pairs))
```

### 输入和输出怎么看

只输出两对，第三个词被静默忽略，因为 labels 更短。

## 最容易踩的坑

长度不等时 zip 不报错，容易悄悄丢数据。Python 3.10+ 可用 zip(a, b, strict=True) 让不等长时报错。
