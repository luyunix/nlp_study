## 真正看懂本节：近邻分数到底在比较什么

假设二维示意向量：

```text
语言 = [1.0, 1.0]
文字 = [0.9, 1.1]
汽车 = [-1.0, 0.0]
```

近邻通常比较余弦相似度，也就是两个向量方向是否接近。“语言”和“文字”方向相似，分数较高；“汽车”方向差异大，分数较低。真实向量可能有 50、100 或更多维，计算思想相同。

相似度高表示它们在训练语料中具有相近的分布使用方式，不保证同义，更不保证事实关系正确。反义词也可能因为经常出现在相似句型中而接近。

### 一个固定评估表应该包含什么

不要临时挑“语言”这一词。预先列出：

| 类型 | 示例目标 | 要观察什么 |
|---|---|---|
| 高频通用词 | 语言、城市 | 基础关系是否稳定 |
| 低频词 | 小众术语 | 是否被噪声主导 |
| 领域词 | 退款、工单 | 是否符合业务语境 |
| 歧义词 | 苹果、银行 | 静态向量能否暴露混合词义 |
| OOV/变体 | 新产品名、拼写变体 | 子词组合是否产生合理但不过度自信的向量 |

对所有模型配置复用同一张表，记录近邻而不是只留漂亮截图。

### FastText 有 OOV 向量，为什么仍需谨慎

字符 n-gram 能把未见词拆成已学过的片段并组合向量，所以 `get_word_vector` 往往能返回固定维度。但若新词的字符片段与真实语义无关，返回值仍可能不可靠。“能返回数组”只证明接口完成，不证明模型认识这个词。

### 最终以任务指标作决定

若目标是客服分类，就把不同词向量固定或微调后接入同一分类器，保持数据划分和训练设置一致，比较宏平均 F1、少数类召回和稳定性。内在近邻用于诊断空间，下游指标用于判断它是否解决实际问题，两者不能相互替代。

## 零基础精讲：把这一节慢下来

### 先看一个具体场景

模型说“语言”的近邻是“文字、语法、中文”，看起来合理，但一个漂亮例子可能只是巧合。评估要用一批固定词和下游任务反复验证。

### 数据究竟怎样一步步变化

1. 加载训练时保存的同一模型
2. 查询词对应的向量
3. 用余弦相似度寻找近邻
4. 再用批量样例或任务指标验证

把上面四步和流程图对照起来：

> 加载模型 → 查询词向量 → 计算近邻 → 人工+任务评估

这里的箭头表示“左边的数据经过一次处理，变成右边的数据”，不是四个需要孤立背诵的名词。

### 第一次读代码，只盯住这一件事

先看 vector.shape 是否等于训练维度，再看近邻的 score 和 word；分数只表示空间位置，不表示事实正确。

运行前先在纸上写出你预计的结果；即使猜错，也要指出自己是在哪个箭头上理解错了。这样比复制代码后看到“能运行”更接近真正学会。

## 老师原声整理稿（按讲解顺序）

### 0:00–2:54　评估先分“直观看”与“任务验证”

老师准备加载已保存模型，查看单词向量和最近邻。最近邻能直观判断相似词是否合理，但属于内在/主观检查；真正项目还要在下游分类、检索等验证集上量化。

### 2:54–5:52　get_word_vector 返回 dim 个数字

```python
model = fasttext.load_model(path)
vector = model.get_word_vector("目标词")
```

若 dim=100，返回形状 [100]。老师打印具体数值并尝试一个个人名字。标准 FastText 可用字符 n-gram 为未登录词组合向量，因此 OOV 不一定报错；得到向量也不等于语义一定可靠。

### 5:52–8:46　get_nearest_neighbors 看近邻

```python
model.get_nearest_neighbors(word, k=10)
```

返回若干（相似度，词）。老师说明默认数量并用它检验模型是否学到语义关联。

相似度通常基于向量空间方向，表示分布式用法接近，不保证事实关系、因果或同义。

### 8:46–11:37　多查几组，不要挑成功案例

课堂观察前几个近邻“还不错”，并建议更多语料改善质量。更可靠流程是固定一批常见词、低频词、领域词和歧义词，批量记录结果。

若目标是情感分类，最近邻合理仍不足以证明有效；应把向量放入分类器，与随机/其他预训练表示比较验证 F1。

## 零基础先记住

- fasttext.load_model(path) 恢复模型
- get_word_vector(word) 返回长度为 dim 的 NumPy 向量
- get_nearest_neighbors(word) 返回（相似度，词）列表

## 最小可运行代码

在项目根目录运行下面代码。课程原理的标准库版本集中在 [text_preprocessing_from_scratch](../../text_preprocessing_from_scratch/README.md)；需要 jieba、PyTorch、FastText 等的示例，请先按代码注释安装依赖。

```python
import fasttext
model = fasttext.load_model("wiki_skipgram.bin")
vector = model.get_word_vector("语言")
print(vector.shape)
for score, word in model.get_nearest_neighbors("语言", k=5):
    print(round(score, 3), word)
```

### 输入和输出怎么看

先看到向量形状，再看到若干相近词及分数。分数高只表示向量空间相近，不等于事实关系成立。
